crocwork Motion portable mode

While this file sits next to effectcraft.exe, crocwork Motion keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the EffectCraftData folder beside it instead of
%APPDATA%\crocwork Motion. Copy the whole folder to move crocwork Motion with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\crocwork Motion unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\crocwork Motion) instead.
If EffectCraftData can't be written (for example on a read-only drive), crocwork Motion logs a
warning and uses %APPDATA%\crocwork Motion instead.
